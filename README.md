# Getting Started

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

---

# Production

Build the application:

```bash
npm run build
```

Start production server:

```bash
npm run start
```
